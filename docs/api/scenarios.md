# Scenarios API

Generated by the entropios scope scale engine (seed 7331).


## Scenarios API

The **Scenarios API** endpoint provides programmatic access to the entropyscope
simulation state.

### Base URL

`http://localhost:3000/api/scenarios`

### Authentication

No authentication is required. All endpoints are read-only by default.

## Endpoints

### GET /api/scenarios

Returns the current state of the scenarios resource.

**Response:**

```json
{
  "seed": 7331,
  "data": {}
}
```

## Errors

| Status | Meaning |
|--------|---------|
| 200 | OK |
| 404 | Not found |
| 500 | Server error |
